test_calendar.py (20 tests)
  Tests the dim.Calendar table generation
  Validates: Date ranges (36K rows), gaps, fiscal years, weekends, partitioning
  Key Assertion: No gaps in dates from 1980-2080

test_store_states.py (15 tests)
  Tests the store.States table generation
  Validates: 5 hardcoded states, tax rates, state codes
  Key Assertion: Exactly 5 states with proper tax rate range

test_store_locations.py (20 tests)
  Tests store.Locations table generation (200 locations)
  Validates: Modulo state cycling, zip code formula, phone format
  Key Assertion: ZipCode = 90000 + (LocationID % 1000)

test_store_operating_hours.py (20 tests)
  Tests store.OperatingHours table generation (1,400 rows)
  Validates: 7 days per location, hardcoded times, day cycling
  Key Assertion: All hours are 08:00-22:00

test_emp_positions.py (20 tests)
  Tests emp.Positions table generation (4 positions)
  Validates: Hierarchy levels, salary ranges, position names
  Key Assertion: MinSalary < MaxSalary for all positions

test_emp_employees.py (25 tests)
  Tests emp.Employees table generation (1,000 employees)
  Validates: Position cycling (1-4), location cycling (1-200), email formula
  Key Assertion: Email format = FirstName.LastName@spicyfiesta.com

test_emp_schedules_timetracking_payroll.py (20 tests)
  Tests 3 tables: Schedules (30K), TimeTracking (30K), Payroll (1K)
  Validates: Shift times, clock calculations, payroll aggregation
  Key Assertion: NetPay = GrossPay - Deductions

test_menu_categories_items_recipes.py (24 tests)
  Tests 4 tables: Categories (4), Items (300), Ingredients (7), Recipes (~1000)
  Validates: Price formula, category cycling, recipe mappings
  Key Assertion: BasePrice = 1.99 + (ItemID % 10) * 0.75

test_inventory_items_storeinventory_po_shipments.py (22 tests)
  Tests 4 tables: Items (7), StoreInventory (1.4K), POs (600), POItems (1.8K)
  Validates: 1:1 item mapping, PO generation, line totals
  Key Assertion: LineTotal = Quantity × UnitCost

test_promotions.py (20 tests)
  Tests 3 tables: Promotions (2), PromotionItems (50), PromotionStores (200)
  Validates: Discount XOR logic, item mappings, store assignments
  Key Assertion: Each promotion has items 1-50 and all 200 stores

test_loyalty_members_points_rewards.py (24 tests)
  Tests 2 tables: Members (2K), Rewards (2)
  Validates: Member numbering format, email generation, reward definitions
  Key Assertion: MemberNumber = MBR-{i:07d}, Email = member{i}@example.com

test_orders.py (20 tests) [LARGEST]
  Tests 8 tables: Orders (5M), OrderItems (12.5M), Payments, Receipts, etc.
  Validates: Complex formulas, modulo cycling, large-scale generation
  Key Assertion: TotalAmount = Subtotal + Tax + Fee + Tip - Discount

test_finance_daily_sales_store_expenses.py (20 tests)
  Tests 2 tables: DailySalesSummary (200K), StoreExpenses (200)
  Validates: Aggregations, averages, expense calculations
  Key Assertion: AverageOrderValue = GrossSales / TotalOrders

test_audit_system_error.py (20 tests)
  Tests 3 tables: SystemConfiguration (1), AuditLog (0), ErrorLog (0)
  Validates: Config singleton, audit/error skeleton schemas
  Key Assertion: Exactly 1 system configuration record
