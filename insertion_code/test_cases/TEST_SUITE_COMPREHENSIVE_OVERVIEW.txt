     - Default tolerance=0 for exact match
     - Parameterized tolerance for large datasets

  3. assert_column_values_in_range(df, column, min_val, max_val)
     - Verify all values in column within [min, max] inclusive
     - Returns count of out-of-range values

  4. assert_no_nulls_in_columns(df, columns)
     - Verify no NULL values in specified column list
     - Multi-column validation

  5. assert_unique_values(df, column, expected_count)
     - Verify distinct count matches expected
     - Validates uniqueness constraints

  6. assert_data_type(df, column, expected_type)
     - Verify column data type matches expectation
     - Supports string representation of types

  7. assert_value_distribution(df, column, expected_dist)
     - Verify value distribution matches expectations

================================================================================
TROUBLESHOOTING GUIDE
================================================================================

Issue: "Import pytest could not be resolved"
  → Expected in local environment, resolves in Databricks
  → Install locally: pip install pytest

Issue: "Parquet file not found"
  → Run generators first to produce parquet files
  → Check output_root fixture path
  → Verify generators completed successfully

Issue: "Row count assertion fails"
  → Generators may produce variable counts
  → Check generator parameters (n_employees, total_orders)
  → Increase tolerance parameter in assert_row_count()

Issue: "Memory error on large datasets"
  → Use .limit() to sample data for testing
  → Reduce spark parallelism
  → Enable spill-to-disk: spark.conf.set("spark.sql.shuffle.partitions", "256")

Issue: "NULL values in critical columns"
  → Check generator logic for missing assignments
  → Verify upstream dependencies are executed
  → Debug with df.filter(df.column.isNull()).show()
